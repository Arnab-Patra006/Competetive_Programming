# Networking Protocols
- Network protocols defines the rules i.e two systems can communicate with each other.
- 7 layers of protocols:
## Application Layer
1. Client-Server
## HTTP / HTTPS (Hypertext Transfer Protocol / Secure)
📦 Used for: Browsing websites

🔐 Why HTTPS: It encrypts the data, so no one can spy on what you're doing.

📌 Example: When you open https://google.com, your browser uses HTTPS to talk to Google servers.

## FTP (File Transfer Protocol)
📦 Used for: Uploading/downloading files to/from a server

❗ Why: Simple for transferring large files

📌 Example: A developer uploading a website to a hosting server might use FTP.

## SMTP (Simple Mail Transfer Protocol)
📦 Used for: Sending emails

✉️ Why: It's the standard protocol for pushing mail out from your email client (like Gmail or Outlook).

📌 Example: When you hit "Send" on an email, SMTP takes it from you to the receiver’s server.

## IMAP / POP3
📦 Used for: Receiving emails

🔄 IMAP: Syncs email across devices

📥 POP3: Downloads and removes email from server

📌 Example: IMAP keeps your email the same on phone & laptop, while POP3 stores it only on one device.
